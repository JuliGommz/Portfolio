## 🚀 Deployment Instructions

### **Option 1: Strato.de FTP Upload**

1. Connect to Strato FTP server
2. Navigate to your web directory (usually `/` or `/html`)
3. Upload entire `portfolio-julian-gomez` folder contents
4. **Important:** Upload folder structure, not just files
5. Verify at: `https://yourdomain.com/`

### **Option 2: Local Testing**

1. Open `index.html` directly in browser
2. Or use local server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx http-server
   ```
3. Visit: `http://localhost:8000`

## 📦 Adding Media Files

## 🔧 Customization

### **Update Project Data**
Edit `js/main.js` → `projectData` object

### **Change Colors**
Edit `css/styles.css` → `:root` variables (lines 14-50)

### **Modify Content**
Edit `index.html` → HTML content
