# Project Images

Place project screenshots and thumbnails here.

## Naming Convention:
- `{projectname}-thumbnail.jpg` - For modal header (120x120px minimum)
- `{projectname}-{number}.jpg` - For gallery (1920x1080px recommended)

## Example:
- `mindsetplay-thumbnail.jpg`
- `mindsetplay-1.jpg`
- `mindsetplay-2.jpg`
- `gourmet-thumbnail.jpg`
- `gourmet-gameplay-1.jpg`

## Recommended Formats:
- **JPG** for photos/screenshots (smaller file size)
- **PNG** for graphics with transparency
- **WebP** for optimal web performance (if supported)

## Optimization:
Compress images before upload to reduce page load time.
Tools: TinyPNG, Squoosh, ImageOptim
