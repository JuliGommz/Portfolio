# Project Videos

Place project videos here or use embed codes.

## Naming Convention:
- `{projectname}-demo.mp4`
- `{projectname}-gameplay.mp4`

## Example:
- `gourmet-gameplay.mp4`
- `chess-demo.mp4`

## Recommended Formats:
- **MP4 (H.264)** - Best browser support
- **WebM** - Smaller file size, modern browsers
- **Provide both** for maximum compatibility

## Alternative: Video Embeds
Instead of hosting videos, you can use:
- YouTube embeds
- Vimeo embeds
- Google Drive links

Edit the modal gallery section in `js/main.js` to add embed codes.

## Optimization:
- Compress videos before upload
- Recommended resolution: 1920x1080 (Full HD)
- Keep file size < 50MB per video
- Tools: HandBrake, FFmpeg, CloudConvert
